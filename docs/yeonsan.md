# 연산교차로(부산 연제구) 시나리오

- 위치: 35.18606, 129.08174 (OSM에서 `연산교차로` 노드 확인), 반경 280m
- 데이터: `data/osm/yeonsan.osm` (© OpenStreetMap contributors, ODbL, Overpass 2026-11-03)
- 구조: 중심에 진입 6방향·출진 6방향 신호교차로(고분로, 반송로, 월드컵대로, 중앙대로), 현시 15개
- 보도·횡단보도 131개, 보행자 시간당 약 240명, 차량 시간당 약 900대(무작위 출발·도착), 일반 차량 4종 혼합
- 재현: `SUMO_HOME=~/src/sumo-1.27.1-mesa tools/build_junction.sh yeonsan 35.18606 129.08174 280`

## 가정·한계
- 신호 현시는 SUMO 자동 생성 값(실제 아님). OSM이 신호를 정지선에 찍어서, 60m 안의 교차점으로 승격해 사용
- 교통량·회전 비율은 실측이 아닌 무작위(randomTrips)
- 학습 환경(`sumo_env.py`)에는 연결하지 않음
